# SONFH基因层面比较：探索性结果与正式limma运行脚本

## 目的
本分析仅用于比较单基因层面的差异表达与现有基因集评分结果，不替代已冻结的85基因集、21功能组和11组相反过程主分析。

## 当前探索性结果（HC3线性回归，不是limma）
输入：GSE123568的40例、18,833基因log2表达矩阵；模型为表达值 ~ SONFH组别 + 性别；每个基因采用HC3稳健标准误，BH校正覆盖全部18,833个基因。

- 全部基因：4,780个名义P<0.05；1,427个全基因组BH-FDR<0.05。
- 过氧化氢分解基因集：24个冻结成员中22个可测；19/22的组别系数为负；8/22名义P<0.05；4/22在全18,833基因校正后FDR<0.05（SNCA、PRDX2、GPX1、EPX）。
- 过氧化氢生成基因集：18个冻结成员中16个可测；10/16的组别系数为负；7/16名义P<0.05；1/16在全基因组校正后FDR<0.05（ACOX1，正向）。

以上是探索性比较，不能直接称为正式的limma DEG结果，也不能据此声称基因集分析普遍优于单基因分析。它仅提示：基因集层面的显著关联与成员基因逐个达到FDR显著并非同一统计问题。

## 正式基因层面分析
在原始SONFH_Research项目根目录运行：

```r
source("run_limma_DEG_comparison.R")
```

脚本使用limma的线性模型及经验贝叶斯调节，设计为 `expression ~ group + sex`，参考组为糖皮质激素暴露但无SONFH组。BH校正范围为全部可测基因。脚本会在`09_DEG_Comparison`下输出全基因结果、两个过氧化氢基因集成员结果、摘要和sessionInfo。

## 解释边界
1. 这是一项事后增加的、范围有限的比较分析；应标为exploratory，不取代预定义主分析。
2. 先检查limma正式结果，再决定是否纳入补充材料；不要只报告有利的基因。
3. 单基因差异表达和基因集评分检验不同假设。不能由某种方法显著而另一种不显著，就断言某种方法普遍更优。
4. 血细胞组成混杂仍未排除；单基因分析不能解决该问题。
5. 本目录中的HC3初步结果不是limma结果。正式稿件应以运行R脚本后的结果为准。
